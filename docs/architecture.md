# Архитектура проекта Support Service

## Назначение

Проект предназначен для учёта заявок
службы технической поддержки.

## Структура каталогов

- data/raw — исходные записи.
- data/processed — обработанные данные.
- src/models — модели и сущности.
- src/dictionaries — справочники.
- src/config — настройки проекта.
- tests — тестовые проверки.
- docs — документация.

## Правила организации

1. Использовать единый стиль именования.
2. Не дублировать каталоги.
3. Разделять данные, код и документацию.
4. Хранить тесты отдельно от основного кода.

## Подготовка к A2 и A3

A2 — единые правила оформления кода.

A3 — модульные тесты для проверки
правильности работы компонентов.
