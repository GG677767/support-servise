# Настройки проекта

## Общая информация

Название проекта: support-service

Назначение: каталог заявок службы поддержки.

## Формат данных

- Формат хранения: CSV
- Кодировка: UTF-8
- Разделитель: точка с запятой (;)
- Формат даты: YYYY-MM-DD
- Язык описаний: русский

## Правила обработки

1. Каждая заявка имеет уникальный ID.
2. Все даты записываются в одном формате.
3. Приоритет выбирается из справочника priorities.csv.
4. Статус выбирается из справочника statuses.csv.
5. Все обязательные поля должны быть заполнены.

## Правила именования

- Названия папок пишутся маленькими буквами.
- Слова разделяются нижним подчёркиванием.
- Документация хранится в формате Markdown.
- Таблицы хранятся в формате CSV.
