# Тестирование проекта

В этой папке будут храниться модульные тесты проекта.

## Планируемые проверки

1. Проверка уникальности ID заявок.
2. Проверка формата дат.
3. Проверка обязательных полей.
4. Проверка допустимых приоритетов.
5. Проверка допустимых статусов.
6. Проверка корректности данных клиентов.

На текущем этапе тесты еще не реализованы.

Папка подготовлена для дальнейшего изучения Unit-тестирования.
